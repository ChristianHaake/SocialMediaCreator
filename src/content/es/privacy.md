## 2. Tratamiento local del contenido del usuario

Los textos, las métricas, las imágenes seleccionadas, los archivos de proyecto importados y los archivos de configuración compatibles se procesan localmente en el navegador. La aplicación no tiene sistema de cuentas, base de datos ni almacenamiento de este contenido en el servidor.

Las exportaciones de imágenes, PDF y proyectos se generan localmente. Los archivos `.smc` contienen copias optimizadas de las imágenes seleccionadas. Se crean o leen únicamente en el dispositivo y no se envían al operador.

## 3. Almacenamiento local

La aplicación utiliza `localStorage` para guardar en el dispositivo el idioma seleccionado y la confirmación del aviso de exportación. IndexedDB almacena la sesión actual, incluidas las imágenes locales, para poder restaurar el trabajo tras recargar la página. La aplicación no envía estos datos al operador. Puedes eliminarlos mediante el botón **Borrar datos** o las funciones del navegador.
